# Tennis Stroke Classification

## Overview
This project aims to classify tennis strokes by skill level (beginner, advanced) and 6 different stroke types using data from the [THETIS dataset](https://github.com/THETIS-dataset/dataset).

## Structure
- `data/`: Contains raw and processed data.
- `src/`: Source code for the project.
- `models/`: Saved models.
- `tests/`: Unit tests.

## Setup
To install the project:
   ```bash
   uv pip install -e .
   ```
Or:
   ```bash
   uv pip install -e '.[dev]'
   ```
